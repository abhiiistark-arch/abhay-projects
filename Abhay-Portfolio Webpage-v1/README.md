# Abhay Pandey — Portfolio

A refined, atmospheric, deeply cinematic single-page portfolio website for Abhay Pandey — AI Engineer, Generative AI Specialist, and Full-Stack Developer based in Mumbai.

## Design Philosophy

- **Dark Cinematic Minimalism**: Deep space blacks with warm amber accents inspired by sunset photography
- **Cyber-Tech Elegance**: Subtle electric cyan accents for AI/tech feel
- **Premium Editorial**: Hairline rules, massive display typography, refined spacing
- **Intentional Motion**: Smooth scroll via Lenis, parallax layers, staggered reveals

## Tech Stack

- Next.js 14 (App Router, TypeScript)
- Tailwind CSS
- Framer Motion
- Lenis (smooth scroll)
- Lucide React (icons)

## Sections

1. **Hero** — Layered parallax with cinematic background, massive typography, floating stats
2. **About** — Editorial bio with strengths timeline
3. **Projects** — Anne (Voice Bot), Smriti (RAG System), Jio Insurance Agents
4. **Experience** — Timeline with RBHU ETG, PassionBytes, RDC Concrete
5. **Contact** — Frosted glass form with cinematic background

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Build

```bash
npm run build
```

Output will be in `dist/` folder.
